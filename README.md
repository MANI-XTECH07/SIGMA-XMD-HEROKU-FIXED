🗿 Welcome to SIGMA XMD

SIGMA XMD is a powerful WhatsApp Multi-Device bot built with Node.js and the Baileys library.

Designed for group management, automation, entertainment, media utilities and everyday WhatsApp tasks, SIGMA XMD provides a modular command system that can be customized and expanded.
